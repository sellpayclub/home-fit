# HOME FIT

Projeto criado com o CodAí.

## Como executar localmente

```bash
npm install
npm run dev
```

Depois, abra [http://localhost:3000](http://localhost:3000).

## Como publicar

Você pode publicar este projeto na Vercel, em qualquer hospedagem compatível com Next.js ou continuar editando-o no CodAí.
